# 织灵使用指南

本指南对应 0.2.6 开发预览版。首次使用建议先完成本机对话，再配置 QQ 和 Agent 任务。

## 1. 安装与启动

从 [0.2.6 下载页](https://github.com/yoouke/PersonaWeave/releases/tag/v0.2.6) 的 Assets 下载文件，无需登录 GitHub。选择 `Setup.exe` 安装版，或解压 `Portable.zip` 使用便携版；同时下载 `SHA256SUMS.txt`，用于核对文件。开发过程中的构建产物仍可在 [Windows 构建页面](https://github.com/yoouke/PersonaWeave/actions/workflows/windows.yml) 获取。

软件已包含 Python 和桌面依赖。桌面窗口需要 WebView2；Agent 引擎、通信服务与插件按所选功能准备。

## 2. 配置模型

打开「偏好与安全」，填写运行 API 地址、模型名称和 API Key，执行连接测试。创作 API 单独配置，可与运行 API 使用不同服务。

使用兼容 API 时，默认 DSH 路由为 `personaweave`。上下文窗口和输出上限应按实际模型能力填写。使用 `deepseek-official` 路由时，在 DSH 控制台完成对应认证。

联网创作还需选择并配置 SearXNG 或 Tavily 搜索服务。自动提取记忆会产生额外模型请求。

## 3. 创建角色

在「人格工坊」选择一种方式：

| 方式 | 操作 |
| --- | --- |
| AI 辅助创作 | 描述角色，与 AI 讨论后确认文案 |
| 导入设定 | 粘贴提示词，或导入 MD / TXT 文件 |
| 联网创作 | 输入角色描述，搜集资料后生成设定并核验来源 |

保存后可继续修改人格、行为规则和形象资料。选择默认角色，再进行后续环境与通信配置。

若先体验本机聊天，可选择纯对话引擎。使用 Agent 任务则需要准备 DSH。

## 4. 准备 Agent 环境

在「初始化向导」检查并安装独立 Node.js、DSH 和插件包管理器。当前锁定的 DSH 版本为 `0.2.1-rc.5`，安装需要网络。

维护任务在总览显示状态。失败后先查看失败步骤，再重试；不要将组件安装成功当作账号登录或模型调用已成功。

## 5. 配置 QQ 通信

QQ 需要运行通信服务及协议端。使用插件通信通道时，先准备一个独立 AstrBot 实例，并在其控制台连接所选协议端、扫码登录 QQ。

NapCat 与 SnowLuma 对同一 QQ 通道二选一。SnowLuma 需自行安装，织灵连接兼容服务。连接已有通信实例后，不要再为该角色启动第二个 NapCat。

在「插件与能力」填写本机后台地址、账号和密码，连接角色的 AstrBot 实例。地址例如 `http://127.0.0.1:6185`。每个角色使用独立实例和数据目录，一个实例地址不能绑定多个角色。

在织灵绑定主人 QQ，并在通信控制台配置：

- 主人是唯一管理员。
- 开启消息白名单。
- 白名单仅包含主人私聊。

插件通信通道当前仅支持这一权限范围。机器人登录账号与主人身份是两个不同概念。

## 6. 准备组件与同步人格

点击「一键准备默认角色基础组件」，依次准备长期记忆、AstrBot 桥接、DSH ingress 和人格设定。该操作针对设置中的默认角色。

重复执行会检查已有 AstrBot 插件并保留其配置。新装插件保持停用，先在插件控制台配置模型、记忆所需服务及凭据，再启用。安装 DSH 插件前需停止原生 DSH 控制台。

人格可手动同步，也可以明确开启自动同步：

- 保存角色及重新联动时同步变更。
- 同步失败保留本地修改，并显示待同步状态。
- 关闭自动同步后，仅手动操作才同步。
- 同步是单向更新人格，不合并插件记忆。
- 已启动 DSH 进程的设定不会即时更新，需要停止并重新启动。

宿主「记忆与关系」页面与通信插件的记忆分别管理，尚无统一迁移。

## 7. 连接任务通道

启动当前角色的原生 DSH 控制台，配置模型、工作区与权限。确认两侧桥接插件已安装后，点击「配置主人专用 DSH 桥」。

使用织灵启动的本角色 DSH 时，外部 token 可留空，由程序读取进程对应的连接信息。连接外部 DSH 时，按插件配置填写 ingress 地址和 token。

主人通过 QQ 私聊发送：

```text
/dsh 你的任务
```

普通角色聊天由通信服务处理，带命令的任务交给 Agent。真实 QQ 往返尚未完成账号验收。

未连接 AstrBot 的配置也可选择「通信平台」中的 OneBot 直连路径；其连接与命令单独管理，不与插件通信通道同时接管同一角色。

## 8. 检查连接与处理故障

点击「逐项检查连接」查看后台认证、主人权限、人格同步、桥插件和当前角色 DSH 进程。后台接口可访问不代表 QQ 已登录；登录状态仍需查看通信控制台。

| 提示 | 处理方法 |
| --- | --- |
| 后台认证失败 | 检查地址、服务进程和后台账号 |
| 主人权限不符合要求 | 检查唯一管理员与私聊白名单 |
| 人格尚未同步 | 手动同步，或开启自动同步后重新联动 |
| 桥接未安装或未启用 | 准备组件并完成桥接配置 |
| 其他角色 DSH 仍在运行 | 先停止旧角色控制台，再启动当前角色 |
| 基础组件准备失败 | 查看中断步骤，修复后重试 |
| QQ 登录待验证 | 打开协议端控制台检查登录状态 |

## 9. 扩展与日常管理

在「插件与能力」选装画图等能力。画图需配置独立图像服务，聊天模型 API 不自动提供图像生成。QQ 图片回传仍待验证。

在监控页面配置模型单价和预算。未设置单价时，费用显示为 0 不代表服务免费；插件内部请求也可能不在宿主统计范围内。

按需要开启后台运行、托盘和开机启动，定期导出角色资料或备份数据。默认公开资料包不包含私人记忆和聊天记录；私密备份请单独保管。
