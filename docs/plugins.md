# 插件与扩展

织灵通过插件为角色增加记忆、表达、消息处理、图像生成与工具能力。插件按实际运行环境配置，同一个角色可以同时关联通信插件、Agent 插件和 MCP 服务。

## 选择合适的接入方式

| 类型 | 配置入口 | 适用范围 |
| --- | --- | --- |
| 通信插件 | 「插件与能力」中的 AstrBot 实例管理区 | 长期记忆、表情包、主动聊天、QQ 功能与任务桥接 |
| DSH 原生插件 | 原生 DSH 控制台与安装入口 | Agent 工具、图像生成和带独立界面的能力 |
| DSH 模块 / Bundle | 高级插件登记与角色开关 | 按 SDK 运行配置加载的模块 |
| MCP 服务 | 插件登记中的 MCP 配置 | 通过标准工具接口连接的服务 |

通信插件在绑定实例中运行；DSH 的 web 与 SDK 运行配置分别管理。安装到其中一种环境，不代表已经在另一种环境加载。

## 基础组件准备

完成模型、默认角色、DSH 和独立通信实例配置后，可以点击「一键准备默认角色基础组件」，准备长期记忆与双端任务桥，并同步人格。

操作需要主人是通信实例唯一管理员，且消息白名单只包含主人私聊。已安装的 AstrBot 插件会跳过安装；新装插件保持停用，待用户配置后启用。失败时显示中断步骤，已完成的安装保留。

详细步骤见 [使用指南](getting-started.md)。

## 通信插件管理

管理区提供以下插件的安装与状态入口：

| 能力 | 插件标识 |
| --- | --- |
| 长期记忆 | `astrbot_plugin_livingmemory` |
| 群聊表达 | `astrbot_plugin_group_chat_plus` |
| 表情包 | `meme_manager` |
| 主动聊天 | `astrbot_plugin_proactive_chat` |
| QQ 空间 | `astrbot_plugin_qzone` |
| QQ 资料 | `astrbot_plugin_qqprofile` |
| 任务桥接 | `astrbot_plugin_dsh` |

列表是可选择的能力，不代表这些插件已经安装、配置或完成真实平台验收。当前通信插件路径限定主人私聊，群聊相关插件的存在不代表已经开放群聊权限。

可读取实际安装状态，安装、启用、禁用、更新和重载插件。桥接插件的启用需要通过主人权限检查；更新时先在控制台停用，再重新配置桥接。

每个角色连接一个独立实例。人格支持手动或自动单向同步，插件记忆保存在其运行环境内，与宿主记忆分别管理。

## Agent 原生能力

提供 `dsh-astrbot-ingress@0.3.23` 和 `dsh-image-gen@0.10.2` 安装入口，安装到当前默认角色的 web 运行配置中。安装前停止原生 DSH 控制台。

启动控制台后，在插件自己的配置页面设置模型、服务及凭据。图像服务可以独立于聊天模型；安装画图插件不代表已获得图像服务权限，也不代表已经验证图片回传 QQ。

## 模块与 Bundle

在高级登记区填写包名、文档、能力分类、使用说明、权限描述及配置，建议固定确切版本。安装与启用分别管理，按角色选择加载。

Bundle 需要填写原生条目 ID。核心人格与凭据条目不能由此覆盖。基础 JSON Schema 支持字符串、数字、布尔和枚举表单，复杂结构使用 JSON 配置。

文档用于查阅；明确填写的「Agent 使用说明」会加入上下文。已有 Skill 时可不重复填写说明。

## MCP 服务

示例配置：

```json
{
  "serverName": "browser",
  "transport": "stdio",
  "command": "npx",
  "args": ["-y", "你选择的MCP包@确切版本"],
  "env": {
    "SERVICE_KEY": "${credential:PW_BROWSER}"
  },
  "startupTimeoutMs": 30000
}
```

也支持 `streamable-http` 与 `url`。在凭据区保存对应值，配置通过引用读取，不应将 Key 直接写入角色文件。

MCP 工具的实际范围由服务决定。插件权限描述用于理解和配置能力，不构成操作系统级沙箱；本地命令和插件可能以当前用户权限运行。

## 搜索与其他能力

npm 搜索用于查找候选包和阅读资料，不会自动安装搜索结果。浏览器、视频、音乐、内容平台等能力需要选择合适插件并完成配置；当前未提供完整的内置媒体套件。

需要平台账号或 API 的能力，由用户完成相应授权。费用、数据存储和服务限制以所配置的服务为准；插件内部请求可能不计入宿主用量统计。
