# Agent 运行上下文

织灵为运行中的 AI 提供软件说明，帮助它理解用户是在角色宿主中发出需求，而不是要求它开发这个仓库。

## 说明包含什么

- 织灵的定位：本地角色创作、记忆知识管理、通信与 Agent 任务运行。
- 任务如何进入引擎，结果怎样通过当前通道返回。
- 如何处理角色创作、记忆、搜索、画图、文件及电脑操作需求。
- 插件缺少配置或当前没有对应工具时，怎样给出可执行的下一步。
- 人格、记忆与系统权限之间的边界。

源文件：`personaweave/agent-guide.md`。这是一份运行协作说明，不是固定角色模板，也不会自动授予工具权限。

## 如何送给 AI

| 运行路径 | 接入方式 |
| --- | --- |
| 宿主 DSH 任务 | 在 system prompt 中注入说明、运行方式及用户人格；在本角色工作区生成 `PERSONAWEAVE_CONTEXT.md` |
| 原生 DSH 控制台及桥接任务 | 启动本角色控制台时注入并生成说明文件 |
| 本机纯对话 / 受限对话 | 注入说明，并明确此会话没有电脑及插件工具；不生成可操作工作区文件 |
| 通信角色 | 同步人格时一并注入说明，实际工具以通信引擎为准 |

工作区文件只包含公共运行说明，不复制主人身份、凭据、聊天记录或私人记忆。不改写已有的 `AGENTS.md`。角色人格文案仍单独保存在原位置；说明不会被拼回用户原始人格文件。

## 更新与生效

新建的宿主 DSH 任务会重新加载说明。原生 DSH 控制台需停止后重新启动，已经运行的进程不会即时更新。

通信角色需再次同步人格；开启自动同步的角色在保存或重新联动时处理。同步版本校验包含运行说明，说明更新后会显示待同步，而不是误认为人格已经一致。

## 能力边界

运行说明让 AI 理解软件并选择正确流程，不新增后台管理工具。它不能仅凭说明直接修改宿主设置、安装插件或写入长期记忆。实际执行取决于该会话已有的工具、服务、权限和成功结果。

例如，用户说「帮我画图」，Agent 应检查图像工具是否可用，再调用或说明缺少的服务配置；不能因为软件提供安装入口就声称图片已经生成。用户说「改一下角色设定」，有实际管理工具时才应用修改，否则提供文案并指出人格工坊的操作位置。
