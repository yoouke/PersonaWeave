# PRD V0.2 功能覆盖与验收边界

软件 0.2.0 开发预览。该文件说明当前实现，不能用来代替用户设备验收。

| PRD 范围 | 当前实现 | 仍需完成/验证 |
| --- | --- | --- |
| 独立宿主与 Windows 应用 | Python 管理 API、Web UI、WebView2、托盘、安装包 | GUI 系统行为与安装卸载实测 |
| DSH 与引擎隔离 | DSH JSON-RPC、独立纯对话适配器 | 可安装的第三方引擎适配器规范及兼容测试 |
| 多人格 | 独立目录、原始提示词、头像/立绘/语音字段、行为与插件关联 | 语音字段目前为资料保存，未驱动 TTS；跨角色 OS 沙箱未实现 |
| 三种创建方式 | AI 讨论、提示词导入、搜索驱动创作及来源分类 | 搜索与创作服务真实 Key 验证；官方资料由用户核验 |
| 记忆 | 持久化、自动提取、分类、编辑删除、范围隔离、文字检索 | 向量检索是可选后续能力，当前无向量数据库 |
| 知识 | 文本导入、访问范围、检索、上下文片段注入 | PDF/视频直接解析由原生插件提供 |
| QQ | 正向 WS、认证、去重、确认、重连、群内 @ 受限对话、图片主动发送 | 真实扫码、发送与群聊实测；图片/文件接收及转存未完成 |
| 两种协议端 | NapCat 自动下载/生成配置/进程管理；外部 SnowLuma 连接 | 上游版本结构与真实账号兼容性；不自动分发 SnowLuma |
| 通信平台扩展 | Telegram Bot / Discord Bot 私聊适配器 | 实际平台授权与恢复验证；不声称已支持所有平台功能 |
| 插件统一管理 | 原生模块/Bundle/MCP、按角色安装与开关、文档、基础 Schema 表单、凭据引用、npm 搜索 | 复杂嵌套 Schema、兼容矩阵、版本回滚及专门市场 |
| 内容平台与媒体 | 现有 DSH/MCP 插件挂载及能力分类入口 | Bilibili/X/YouTube/音乐/语音实际插件集成测试，不提供虚假的内置成品能力 |
| 身份和权限 | 身份分级、默认拒绝未知用户、非主人无电脑工具、群聊不继承主人记忆 | 非主人目前是受限对话，不开放精细工具白名单；不提供 OS 多租户沙箱 |
| 凭据 | 系统凭据库、MCP 环境引用、已知凭据日志脱敏 | 上游登录缓存/OneBot 原生配置并非全盘加密；不声称全部日志无隐私 |
| 初始化 | 检测、独立 Node/DSH/pnpm、后台部署任务、步骤状态、控制台扫码入口 | 不同空 Windows 环境无人值守验收；必要的账号扫码不能自动代替 |
| 启动联动 | 单实例、可选自动连接、有限协议端恢复、任务重启标记、托盘、自启动 | Windows 休眠/断网/重启与崩溃矩阵；不自动重放副作用 |
| API 监控 | 宿主调用实测/估算标记、DSH canonical usage、角色/模型/用途/周期、单价和预算 | 提供商账单同步及任意插件内部 API 归因尚未完成 |
| 本机监控 | CPU、内存、磁盘、网络累计、服务进程 | CPU 进程百分比是采样参考；未完成 Windows 性能基准 |
| 两个控制台 | 宿主事件/任务/工具日志；已有本机官方控制台统一入口 | 不自动启动 DSH 网页管理服务，不假定 SDK 内有官方 UI |
| DIY 与资料包 | 主题颜色/图标、头像立绘、角色分享及私密备份 | 任意 UI 插件、安全分发市场、安装器换图标、声音及媒体素材包仍待完善 |

## 已执行的外部条件替代测试

- 本机模型 HTTP 服务验证兼容 API 请求、返回与 usage。
- 真实 DSH 0.2.1-rc.5 启动并接收宿主 SDK 请求，调用本机模拟模型，返回任务文本及用量。
- 实际 OneBot WebSocket 模拟端校验 Token，投递消息与重复消息，宿主只执行一次，回复获得协议确认。
- Chromium 验证创建角色、记忆/知识写入、十个页面及刷新认证。
- 以上不等于真实 QQ 账号或真实模型服务验收，相关内容单列保留。
