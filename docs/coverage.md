# 功能状态

对应版本：**0.2.5 开发预览**。本页区分已有实现、使用条件和待完成工作；“已实现”不等于全部真实账号与设备场景都已验证。

## 已有能力

| 领域 | 当前提供的功能 | 使用条件或边界 |
| --- | --- | --- |
| 桌面应用 | Windows 窗口、管理界面、托盘、后台运行、自启动设置、安装包与便携版 | 实际安装卸载、托盘交互和休眠恢复待验证 |
| 角色管理 | 多角色、独立目录、人格与行为编辑、头像立绘、来源资料 | 语音配置仅保存资料，尚无 TTS 播放链路 |
| 角色创作 | AI 讨论、提示词 / MD / TXT 导入、联网创作 | 需配置模型和搜索服务；资料来源需要核验 |
| 宿主记忆 | 自动提取、事实 / 事件 / 关系 / 经历分类、查看编辑删除与文字检索 | 额外模型调用；当前无向量数据库 |
| 知识管理 | 文本导入、范围控制、检索与上下文片段注入 | PDF 与视频直接解析不属于当前内置能力 |
| Agent | DSH 任务、独立工作目录、会话与任务记录、审批 | 目录独立不等于操作系统沙箱 |
| 纯对话 | 兼容 API 的本机对话方式 | 需用户配置可用模型服务 |
| QQ 直连 | OneBot WebSocket、私聊与群内 @ 消息处理、去重、重连及发送确认 | 真实账号收发待验证；图片 / 文件接收转存未完成 |
| 插件通信 | 独立实例绑定、基础组件准备、人格同步、任务桥接配置 | 当前限定主人私聊；通信实例需另行准备 |
| 人格同步 | 手动同步、可选自动同步、待同步状态及失败重试 | 单向同步；不迁移插件记忆，不更新已经运行的 DSH 会话 |
| 协议端 | NapCat 下载校验与进程配置、连接 SnowLuma 兼容端 | 同一通道二选一；SnowLuma 自行安装 |
| 其他平台 | Telegram Bot 与 Discord Bot 私聊适配器 | 实际授权、消息与恢复待验证 |
| 插件管理 | 安装、启停、更新、文档、基础表单、凭据引用、MCP 与 npm 搜索 | 复杂配置、兼容矩阵与回滚尚不完整 |
| 图像生成 | 画图插件安装与原生配置入口 | 需图像服务；真实生成和 QQ 回传待验证 |
| 身份权限 | 主人 / 熟人 / 普通用户 / 未知用户规则、受限对话及审批 | 非主人未开放精细工具白名单；插件通道限定主人 |
| 凭据 | 系统凭据库、运行时引用、已知凭据日志脱敏 | 不保证通信缓存、插件配置、数据库和日志全部加密 |
| 安装联动 | 初始化、后台维护、重新连接、逐项检查、有限进程恢复 | 空白 Windows 环境与系统恢复矩阵待验证 |
| 监控 | 模型请求、Token、角色 / 模型 / 用途 / 周期统计、费用估算与预算 | 尚无服务商账单同步，不能完整归因插件内部请求 |
| 本机资源 | CPU、内存、磁盘、网络与进程资源 | 尚未完成 Windows 性能基准 |
| DIY 与备份 | 主题颜色、图标、角色资料包、私密备份、数据库备份 | 任意 UI 插件、完整媒体资源包及市场待开发 |

## 已通过的自动化验证

0.2.5 集成作业执行全部 **50 项测试**，包括真实 DSH 配合本机模拟模型、HTTP 接口合约、消息协议、角色数据与权限边界。Linux 和 Windows 回归通过。

Chromium 检查覆盖角色创建保存、记忆和知识操作、十个页面、窄屏、认证刷新，以及基础组件准备、自动同步和连接检查入口。

Windows 构建生成安装包、便携版与校验文件，冻结程序的本机服务启动及页面资源检查通过。

构建成功不能代替真实平台登录、付费服务调用和桌面系统行为验收。具体记录见 [验证记录](verification.md)。
