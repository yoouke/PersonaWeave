# 织灵 · PersonaWeave 视觉规范

## 概念

采用用户最终选定的紫色流线蝶形图案。保留原图的轮廓、透明度、渐变与光晕，不重新绘制或改变形状。

主视觉采用月光紫、杏桃和雾白。风格轻盈、温和、清晰；角色资料由用户创作，品牌不预设角色外观。

## 资源

- `design/logo-original.png`：用户提供的原始图案，原文件完整保存。
- `personaweave/web/logo.png`：768px 透明品牌资源。
- `personaweave/web/icon.png`：512px 正方形应用与托盘资源。
- `packaging/icon.ico`：16/24/32/48/64/128/256px Windows 图标。

PNG 与 ICO 由原图等比例缩放、透明留边导出，未拉伸蝶形；原图为位图，不宣称为矢量源文件。原图带有光晕，小尺寸托盘中细节会减少。用户仍可在设置中使用自己的 PNG 图标。

## 配色

| 用途 | 色值 |
| --- | --- |
| Logo | 原图紫色渐变与光晕 |
| 交互强调紫 | `#705BC9` |
| 界面杏桃辅助色 | `#F1AB98` |
| 图标背景 | 透明 |
| 页面雾白 | `#F7F7FB` |
| 浅紫表面 | `#F0ECFA` |
| 正文 | `#302D43` |
| 次级正文 | `#766C85` |
| 边框 | `#E9E7F0` |

浅杏与浅紫只用于表面、装饰和辅助图形；正文使用较深颜色。状态同时使用中文文字，避免仅靠颜色传达结果。

## 字体与布局

系统字体栈为 Segoe UI / 微软雅黑 / 苹方；不从外网加载字体。页面标题 28px，卡片标题 15px，常用文字 12–14px，英文眉题用于低优先级装饰。

左侧分组导航，主区使用 18px 圆角卡片。概览页包含品牌欢迎区、真实状态指标、对话/任务、审批与资源；不使用虚构的角色、任务和调用量装饰页面。人格工坊展示用户角色头像或名字首字。

主交互使用实色强调按钮，辅助操作使用边框按钮。配置根据用途分组；插件复杂文档与开发者配置默认折叠。表单保留原有标签与键盘操作，提供焦点样式、跳转主内容入口和减少动态效果支持。

## 适配与验证

浏览器检查覆盖常规桌面、900px 小窗口及 390px 窄屏，无文档横向溢出。窄屏使用图标导航和竖向状态指标。Windows 桌面实际最小窗口仍遵循程序现有配置；窄屏适配也用于浏览器管理模式。

主题颜色、主题导入导出、用户自定义图标继续保留。窗口背景与图标不改变角色资料、权限、运行引擎或数据位置。
